# Real photos go here

Drop real photos of Joy in this folder (no stock imagery). Until a file exists,
the site shows a calm labeled placeholder in its place, so the page never looks
broken. Filenames the homepage looks for:

- `hero.jpg` — the building (top of the homepage)
- `mellissa.jpg` — a real recent photo of Mellissa
- `community-1.jpg` — front porch / entrance
- `community-2.jpg` — shared dining table with residents and staff
- `community-3.jpg` — a resident's room
- `community-4.jpg` — the common living room

See `../../OPERATIONS.md` for full guidance.
